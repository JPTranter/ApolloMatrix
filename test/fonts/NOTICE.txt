Preview fonts — NOT distributed with this repository
====================================================

The preview harness uses the same two fonts as the firmware, but they are **not**
committed here: they are third-party font software. Fetch them when you need them:

    python test/fetch_fonts.py --download      # simplest — no ESPHome required
    python test/fetch_fonts.py --via-esphome   # byte-identical to the firmware
    python test/fetch_fonts.py                 # copy from a local ESPHome cache

Nothing in the firmware path reads this directory. The `font:` block in
apollomatrix.yaml uses `gfonts://Silkscreen` and `gfonts://Roboto`, and ESPHome
downloads them on the build host. The copies here are only read by:

  * test/rasterize.py            — the caption chrome around each render
  * test/export_font_metrics.py  — regenerating the committed glyph fixtures

Rendering works without them: `metrics.json` is committed, and the caption font falls
back to PIL's default (the suite prints a note saying so). Only *re-exporting* the
fixtures needs a real TTF.

Fidelity: the cache and `--via-esphome` routes give the exact files ESPHome embeds —
verified byte-identical. `--download` pulls the upstream releases instead: Silkscreen is
a static font there, but Roboto ships as a variable font, so its metrics can differ
slightly. Fine for captions; prefer the cache route before regenerating `metrics.json`.

carries the copyright notice and the licence; by keeping the fonts out of this
repository we ship neither the fonts nor that obligation. The OFL texts stay here
because the firmware *does* embed glyph bitmaps derived from these fonts, and because
anyone who fetches the fonts into this directory gets the terms with them.
